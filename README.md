# AI Mock Interview Platform

An AI-powered mock interview system that simulates real interview scenarios, evaluates answers, and provides structured feedback to help users improve their technical and communication skills.

---

##  Features

- Role-based interview generation (Frontend, Backend, Data Science, etc.)
- AI-generated dynamic interview questions
- Real-time answer evaluation using LLM (Gemini API)
- Resume-based question customization (PDF parsing)
- Voice input support for answering questions
- Performance scoring with improvement suggestions
- Clean dashboard for interview sessions and results

---

## Tech Stack
**Frontend:**
- React.js

**Backend:**
-  / Express OR FastAPI
